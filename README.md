# esp-modelbouw-c3

Bestanden voor automatische software-updates van het mini-billboard (C3 SuperMini, 1,8"-scherm, wifi).

**Huidige versie: 2.6** — zie `CHANGELOG.md` voor wat er per versie is bijgekomen.

| Bestand | Wat |
|---|---|
| `billboard_c3.bin` | De nieuwste software. Het bordje haalt die hier zelf op. |
| `herstel_c3.bin` | Vaste versie om op terug te vallen (herstelmodus). |
| `billboard_c3_eerste_installatie.bin` | Volledig bestand voor de allereerste keer flashen (4 MB). |

Niet hernoemen, verplaatsen of verwijderen.
